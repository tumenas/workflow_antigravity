## Core Principles

- **Plan first** — enter plan mode before non-trivial tasks; save plans to `quality_reports/plans/`
- **Verify after** — compile/render and confirm output after every task
- **Single source of truth** — `manuscript/manuscript.qmd` is authoritative; PDF/HTML derive from it
- **Data immutability** — NEVER modify files in `data/raw/`; all edits go to `data/processed/`
- **Quality gates** — nothing is considered done below 80/100 quality score
- **Continuity** — write `quality_reports/session_logs/SESSION_STATE.md` at session end; read it at session start
- **[LEARN] tags** — when corrected, save `[LEARN:category] wrong → right` to `.agents/MEMORY.md`

Cross-session context lives in `.agents/MEMORY.md`.
Past plans and session logs are in `quality_reports/`.

## Workflow Commands

```powershell
# Full pipeline
.\run.ps1 all

# Individual steps
.\run.ps1 env          # Create venv and install dependencies
.\run.ps1 analysis     # Run all Python analysis scripts sequentially
.\run.ps1 paper        # Render manuscript.qmd to HTML/PDF via Quarto
.\run.ps1 clean        # Remove generated files and temp artifacts

# Environment validation
.\scripts\validate-setup.ps1
```

## Academic Skills Reference

| Command (Skill)      | What it does |
|----------------------|--------------|
| `review-paper`       | Multi-mode manuscript review: single-pass, adversarial critic-fixer, or simulated peer review calibrated to a target journal |
| `seven-pass-review`  | Seven-lens parallel review (abstract, intro, methods, results, robustness, prose, citations) — best for submission-ready drafts |
| `verify-claims`      | Chain-of-Verification fact-check: traces every quantitative claim in the manuscript back to the processed dataset |
| `proofread`          | Grammar, spelling, academic style, and sentence-overflow review |
| `humanize`           | Audits academic prose for AI-voice tells — read-only, no rewrites |
| `lit-review`         | Structures a literature search and synthesis plan |
| `research-ideation`  | Brainstorms research questions, model specifications, and robustness checks |
| `interview-me`       | Interactive Socratic interview to elicit and clarify research methodology |
| `qa-quarto`          | Adversarial QA on the compiled Quarto document (layout, references, figures) |

To invoke a skill, paste the content of the corresponding file in `.agents/skills/` and describe your task.
