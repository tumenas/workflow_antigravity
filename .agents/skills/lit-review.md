# Skill: lit-review

**Descrição:** Estrutura um plano de revisão de literatura para um tópico de pesquisa, organizando as dimensões a explorar, estratégias de busca e síntese.

**Como invocar:** `lit-review [tópico ou questão de pesquisa]`

---

## Protocolo

### Passo 1 — Clarificação do Escopo

Antes de iniciar, fazer ao usuário as seguintes perguntas (se não respondidas):
1. Qual é a questão de pesquisa central?
2. Qual é o período temporal de interesse (ex: últimos 10 anos, desde 1990)?
3. Quais são os idiomas relevantes (inglês, português, espanhol)?
4. Há periódicos ou autores de referência obrigatórios?
5. A revisão é narrativa, sistemática ou scoping?

### Passo 2 — Mapa Conceitual

Produzir um mapa das dimensões teóricas a explorar:

```
Tópico Central: [TÓPICO]
├── Dimensão 1: [subdimensão A, subdimensão B]
├── Dimensão 2: [subdimensão C, subdimensão D]
└── Dimensão 3: [subdimensão E, subdimensão F]
```

### Passo 3 — Estratégia de Busca

Para cada dimensão, propor:
- **Termos de busca** (em inglês e português)
- **Operadores booleanos** recomendados
- **Bases de dados** relevantes (Web of Science, Scopus, PubMed, Google Scholar, SSRN)
- **Filtros** recomendados (período, tipo de documento)

### Passo 4 — Estrutura da Síntese

Propor a estrutura de seções para a revisão de literatura no manuscrito:

```
2. REVISÃO DE LITERATURA
   2.1 [Subtítulo baseado na Dimensão 1]
   2.2 [Subtítulo baseado na Dimensão 2]
   2.3 [Lacuna identificada e contribuição do artigo]
```

### Passo 5 — Template de Ficha Bibliográfica

Para cada artigo encontrado, usar o template:

```
**Autor(es), Ano** | Periódico
- Questão: [o que investigam]
- Método: [como investigam]
- Achado principal: [o que encontram]
- Relevância para meu artigo: [como se relaciona]
- Limitação reportada: [o que eles reconhecem como limitação]
```
