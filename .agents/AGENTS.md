## Inicialização de Sessão (Executar Sempre ao Começar)

Ao iniciar qualquer sessão neste projeto, executar obrigatoriamente os seguintes passos:

### Passo 1 — Carregar Regras Sempre-Ativas
Ler e internalizar o conteúdo **completo** dos seguintes arquivos antes de qualquer outra ação:
1. `.agents/rules/meta-governance.md` — princípios invioláveis e hierarquia de decisão
2. `.agents/rules/quality-gates.md` — critérios de qualidade (80/90/95)
3. `.agents/rules/verification-protocol.md` — checklist de verificação final
4. `.agents/rules/session-handoff-protocol.md` — continuidade entre sessões

### Passo 2 — Verificar Estado da Sessão Anterior
Verificar se existe o arquivo `quality_reports/session_logs/SESSION_STATE.md`:
- **Se existir:** ler e confirmar ao usuário: *"Estado da sessão anterior carregado. Paramos em [X], o plano atual é [Y]."*
- **Se não existir:** informar que é uma sessão nova e perguntar o objetivo.

### Passo 3 — Carregar Memória Persistente
Ler `.agents/MEMORY.md` para recuperar aprendizados e convenções estabelecidas em sessões anteriores.

## Core Principles

- **Plan first** — enter plan mode before non-trivial tasks; save plans to `quality_reports/plans/`
- **Verify after** — compile/render and confirm output after every task
- **Single source of truth** — `manuscript/manuscript.qmd` is authoritative; PDF/HTML derive from it
- **Data immutability** — NEVER modify files in `data/raw/`; all edits go to `data/processed/`
- **Quality gates** — nothing is considered done below 80/100 quality score
- **Continuity** — write `quality_reports/session_logs/SESSION_STATE.md` at session end; read it at session start
- **[LEARN] tags** — when corrected, save `[LEARN:category] wrong → right` to `.agents/MEMORY.md`

Cross-session context lives in `.agents/MEMORY.md`.
Past plans and session logs are in `quality_reports/`.

## Academic Skills Reference

Para invocar uma skill: informar o nome da skill e o arquivo-alvo. O agente lerá o arquivo correspondente em `.agents/skills/` e executará as instruções.

| Skill | O que faz |
|-------|-----------|
| `review-paper` | Revisão científica completa: single-pass, adversarial ou peer review simulado calibrado para periódico-alvo |
| `seven-pass-review` | Revisão em 7 lentes paralelas (abstract, intro, métodos, resultados, robustez, prosa, referências) — para rascunhos próximos de submissão |
| `verify-claims` | Rastreia cada número do manuscrito até a fonte nos dados processados (Chain-of-Verification) |
| `proofread` | Revisão gramatical, ortográfica e de estilo acadêmico |
| `humanize` | Detecta padrões de linguagem de IA na prosa científica (read-only) |
| `lit-review` | Estrutura busca e síntese de literatura |
| `research-ideation` | Brainstorming de questões de pesquisa, especificações de modelos e robustez |
| `interview-me` | Entrevista socrática para elicitar e clarificar metodologia |
| `qa-quarto` | QA adversarial do documento Quarto compilado (layout, referências, figuras) |
| `tufte-viz` | Ideação e crítica de gráficos com base nos princípios de Edward Tufte |

**Exemplo de invocação:**
> "Use a skill `seven-pass-review` no arquivo `manuscript/manuscript.qmd`"
