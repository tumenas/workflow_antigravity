# Proofreading Protocol — Revisão de Escrita Acadêmica

## Objetivo

Produzir uma revisão completa de gramática, estilo e fluidez da escrita científica no manuscrito, sem alterar o conteúdo técnico ou científico.

## O que Revisar

### Nível de Sentença
- **Erros gramaticais**: concordância verbal e nominal, uso de artigos, regência.
- **Erros ortográficos**: incluindo termos técnicos e nomes próprios.
- **Pontuação**: vírgulas, ponto-e-vírgula, uso de travessão e parênteses.
- **Frases muito longas**: sentenças com mais de 3 cláusulas subordinadas devem ser divididas.
- **Voz passiva excessiva**: preferir voz ativa quando não houver razão científica para a passiva.

### Nível de Parágrafo
- **Coesão**: cada parágrafo deve ter uma ideia central clara.
- **Transições**: o início de cada parágrafo deve conectar logicamente com o anterior.
- **Redundância**: eliminar afirmações repetidas que não acrescentam informação nova.

### Nível de Seção
- **Progressão lógica**: Introdução → Metodologia → Resultados → Discussão → Conclusão.
- **Consistência terminológica**: o mesmo conceito deve usar sempre o mesmo termo ao longo do texto.
- **Tom acadêmico**: evitar coloquialismos, informalidades e primeira pessoa do singular onde desnecessário.

## O que NÃO Alterar

- Valores numéricos, estatísticas, coeficientes — qualquer alteração numérica requer verificação cruzada com `results/`.
- Nomes de variáveis, métodos ou modelos utilizados.
- Citações e referências bibliográficas — apenas verificar formatação.
- Estrutura de seções — não reorganizar seções sem aprovação explícita.

## Formato do Reporte

Para cada problema encontrado, reportar como:

```
[LINHA/PARÁGRAFO] Problema identificado
  Original: "texto original"
  Sugestão: "texto sugerido"
  Motivo: breve justificativa
```
